# Pocketwise (working name)

Article site in the style of an AdSense-supported news/guide site.

- `articles/` one Markdown file per article (header lines, `---`, then the text)
- `img/` article photos (Pexels, free licence)
- `src/` stylesheet and script
- `build.py` settings at the top (site name, domain, AdSense publisher ID and ad units, analytics); run `python3 build.py` to rebuild `docs/`
